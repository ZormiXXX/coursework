# Учебные работы по информатике

Общий каталог для домашних заданий и лабораторных работ. Каждая работа лежит в своей подпапке и имеет собственную инструкцию по сборке.

```text
coursework/
├── homeworks/hw1/   # ДЗ-1: умные указатели
└── labs/lr1/        # ЛР-1: AVL-дерево поиска
```

Собрать все проекты: `make`. Тесты: `make test`. Подробные команды для отдельной работы находятся в её `README.md`.
