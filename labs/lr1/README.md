# Лабораторная работа №1: AVL-множество

Проект реализует шаблонное множество на сбалансированном бинарном дереве поиска. Внутренние ветви дерева являются закрытой частью `AvlSet<T, Compare>` и владеют дочерними ветвями через `std::unique_ptr`. Операции вращения перемещают владение узлами; контейнеры STL для хранения элементов не применяются.

В [`avl_set.hpp`](include/avl_set.hpp) находятся правила дерева, его операции и текстовый формат. Меню вынесено в [`tree_console.cpp`](src/tree_console.cpp), замеры — в [`benchmark.cpp`](src/benchmark.cpp), запуск режимов — в `main.cpp`. Данные для примеров с предметными типами находятся в тестовой программе.

## Возможности

- вставка, поиск, удаление, AVL-балансировка, высота, размер и доступ к элементу по индексу;
- шесть вариантов обхода, `map`, `where`, `reduce`, слияние, копирование поддерева и проверка его вхождения;
- запись и чтение структуры в формате обхода, например `{К}(Л)[П]`; строки экранируются кавычками;
- шаблонная работа с целыми и вещественными числами, комплексными числами с заданным порядком, строками, указателями на функции, записями студентов и преподавателей;
- ручное меню и генерация случайных значений с количеством, границами диапазона и seed;
- замеры вставки, поиска и удаления на случайных перестановках, до `10^8` ключей при достаточной памяти.

Для вставки, поиска, удаления и индексного доступа сложность `O(log n)` в худшем случае. Обходы и `reduce` работают за `O(n)`. `map`, `where` и слияние строят результат вставками и занимают `O(n log n)`. Память дерева — `O(n)`.

## Сборка и проверки

Из каталога проекта:

```sh
make
make run
make test
make test-sanitize
```

Проверки разделены на шесть групп и содержат более 100 тысяч утверждений, в том числе 20 000 случайных вставок и удалений со сравнением с независимой упорядоченной моделью. Проверяются все типы из варианта, баланс после поворотов, операции с поддеревьями и чтение/запись во всех шести форматах. Счётчик живых узлов используется для проверки освобождения памяти; `test-sanitize` включает AddressSanitizer и UndefinedBehaviorSanitizer.

## Бенчмарк

```sh
make benchmark MAX_SIZE=1000000 SEED=20261116
make graph
```

По умолчанию выбираются 20 размеров от `10^4` до `10^8`; `MAX_SIZE` ограничивает верхний размер конкретного запуска. Для воспроизводимости порядок ключей задаётся seed. Результаты запуска сохраняются в `benchmark.csv`, график — в `benchmark.svg`.

Пример меню: выберите пункт `13`, укажите количество значений, минимум, максимум и seed. Повторяющиеся случайные числа считаются одной записью, поскольку структура является множеством.
